# Continuous and extended models

This page organizes continuous generalization and more flexible CDM extensions. Three things are particularly distinguished here: continuous attribute mastery (continuous attribute mastery), continuous response data (continuous response data) and general response types (general response types).

## Reading target

- Understand how the binary mastery of traditional CDM can be extended to partial mastery.
- Distinguish between the continuous student attribute \(A\) and the continuous item requirement \(Q\).
- Understand the applicable scenarios of continuous response, mixed latent variables and general-response CDM.
- Find a suitable position for subsequent continuous-Q research: what others serialize, we serialize.
