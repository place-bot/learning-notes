# Reference and source boundary

## Main thesis

Xu, G. (2017). Identifiability of restricted latent class models with binary responses. *The Annals of Statistics, 45*(2), 675--707. [DOI](https://doi.org/10.1214/16-AOS1464) · [Project Euclid](https://projecteuclid.org/journals/annals-of-statistics/volume-45/issue-2/Identifiability-of-restricted-latent-class-models-with-binary-responses/10.1214/16-AOS1464.full) · [arXiv](https://arxiv.org/abs/1603.04140)

This site's discussion on models, C1/C2, propositions 1-3, axioms 1-2, five-step proofs, proposition 2 counterexamples and large-sample theory are all based on the full text of this paper.
