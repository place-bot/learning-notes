## Source description

- 1977 The original text is used to check the title, abstract, lower rank range, Theorem 4a and application boundaries.
- The proof page explicitly adopts the modern organization of proofs from Rhodes (2010) for the same Theorem 4a.
- The hand calculation examples on this site and `tools/kruskal_1977_demo.py` are pedagogical reproductions, and the original paper has no official code.
