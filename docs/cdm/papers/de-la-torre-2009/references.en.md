## Source and code description

- The model, appendix formulas, four tables and discussion section are all checked against the 2009 original PDF.
- The original Ox code only states that it can be obtained from the author, and there is no public repository for line-by-line review.
- `tools/de_la_torre_2009_dina_em.py` is a reproduction of the teaching written by this site based on the appendix. It does not pretend to be the author's original implementation.
