## Source Boundary

This topic checks the 18-page Version of Record page by page, and uses PMC to open the full-text review and search the text. The 29-page manuscript on the author's site contains longer background and theoretical material; any content beyond the formal 2012 article is not incorporated into the "original conclusion" of this topic. The 2013 theoretical sequel is reserved for the next topic.

The official version does not have real data, supplemental code, running times or random seeds. The script of this website is an independent teaching implementation.
