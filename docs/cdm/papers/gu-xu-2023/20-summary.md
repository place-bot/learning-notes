# 20 总结、符号与后续问题

## 这篇文章最值得留下的三件事

**第一，测量学生画像可以直接作为估计目标。** joint MLE 将二值 A 与 Q、题目参数共同估计，不必先估计所有画像的总体混合比例。

**第二，统计保证靠的是结构，不只是“大数据”。** 分离信号、重复单属性题、画像覆盖和稀疏题目要求，把小概率损失转成小结构错误比例。

**第三，简单模型可以帮助复杂结构学习，但有条件。** 两参数近似可以先学 A，再逐题回归学 Q；更强信号下甚至一阶段即可恢复结构。不能据此认为模型错设通常没有后果。

## 与 Continuous-Q DINA 的联系和边界

| 可以借鉴 | 不能直接移植 |
| --- | --- |
| A 作为固定未知二值画像的估计视角 | binary-Q 支持识别定理直接变成连续强度识别定理 |
| 联合似然与逐块计算 | 把 ADG-EM 称作穷举画像算法 |
| 共同属性置换与锚点解释 | 没有真实标签却声称能靠 matching 恢复专家语义 |
| 将统计误差与优化误差区分 | 单次局部收敛等于全局 MLE 一致性 |
| 同时报告学生、题目与结构输出 | 本文回归 Stage 2 与另一个模型的 conditional BIC Stage 2 混称 |

本文 A 平均是计算近似；它既不是连续掌握模型，也不是连续 Q。若另一个模型使用连续 Q，应重新检查可识别性、优化目标与参数空间。

## 手推顺序

1. 给定分组，求 Bernoulli 参数 MLE。
2. 推导 \(L-\bar L\) 的 KL 分解。
3. 证明总体损失等于 KL 总和。
4. 用全局最优性得到 \(2U\) 夹逼。
5. 手推混淆表的加权平方偏差。
6. 证明单位阵锚定与不同 Q 的区分画像。
7. 重推 A、Q 两个 Gibbs 条件分布。
8. 推 Theorem 2 的单边错设损失界。
9. 最后逐条核实渐近计数、参数空间与增长条件。
