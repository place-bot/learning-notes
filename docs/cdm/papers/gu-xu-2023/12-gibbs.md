# 12 Gibbs 条件概率：不跳步推导符号

本章直接从 DINA 联合似然推导。结果与 arXiv v3 p.17–18 两条显示公式的符号相反；已核对 PDF 原页，不是文字抽取造成。这里只讨论该底本显示式，不推断作者实际程序必然如此。

## 1. 把每个反应的对数似然写成基线加增量

定义

\[
\psi_{ij}
=r_{ij}\log\frac{\theta_j^+}{\theta_j^-}
+(1-r_{ij})\log\frac{1-\theta_j^+}{1-\theta_j^-}.
\]

那么

\[
\ell_{ij}=r_{ij}\log\theta_j^-+
(1-r_{ij})\log(1-\theta_j^-)+\xi_{ij}\psi_{ij}.
\]

\(\psi\) 是从低概率组切到高概率组的对数似然增量。

## 2. 任意二值坐标的条件分布

若状态1和0的对数权重为 \(\ell_1,\ell_0\)，且没有额外非均匀先验，则

\[
P(x=1\mid-)
=\frac{e^{\ell_1}}{e^{\ell_1}+e^{\ell_0}}
=\sigma(\ell_1-\ell_0),\quad
\sigma(u)=\frac{e^u}{1+e^u}.
\]

所以要算的是“1减0”，不是反过来。若加入先验，还须加先验对数赔率。

## 3. 更新学生属性坐标

令 \(h_{ijk}=\prod_{m\ne k}a_{im}^{q_{jm}}\)。

- \(q_{jk}=0\)：此属性变化不影响题 j；
- \(q_{jk}=1\)：\(a_{ik}\) 从0变1，\(\xi_{ij}\) 从0变 \(h_{ijk}\)。

所以

\[
\Delta\ell_{a_{ik}}
=\sum_j q_{jk}h_{ijk}\psi_{ij},
\]

\[
\boxed{P(a_{ik}=1\mid-)=
\sigma\left(\sum_jq_{jk}h_{ijk}\psi_{ij}\right).}
\]

## 4. 更新题目属性坐标

Q 从0变1，意味着增加要求。原理想反应是 \(h_{ijk}\)，新值是 \(a_{ik}h_{ijk}\)，差为

\[
a_{ik}h_{ijk}-h_{ijk}=-(1-a_{ik})h_{ijk}.
\]

因此

\[
\boxed{P(q_{jk}=1\mid-)=
\sigma\left(-\sum_i(1-a_{ik})h_{ijk}\psi_{ij}\right).}
\]

增加学生掌握与增加题目要求，作用方向恰好相反。

## 5. 一题一属性的验算

令 \(\theta^+=.8,\theta^-=.2,r=1\)。

固定 \(q=1\)，学生掌握概率为

\[
\frac{.8}{.8+.2}=.8.
\]

固定 \(a=0\)，题目要求此属性的概率为

\[
\frac{.2}{.2+.8}=.2.
\]

因为一名未掌握学生答对，会相对支持“题目不要求该属性”。任何实现若返回 .2 和 .8，应先查是否反用了符号或编码。

## 6. Gibbs、bit-flip、穷举分别是什么

| 方法 | 同一坐标或画像如何选择 |
| --- | --- |
| Gibbs | 按条件概率随机抽样，可能暂时降低似然 |
| 贪心 bit-flip | 比较翻转前后，通常只保留更高似然状态 |
| 全画像穷举 | 对该学生全部 \(2^K\) 种画像比较条件似然 |

它们可以服务于相关估计目标，但不是同一个算法。Gu 与 Xu 的 ADG-EM 不应被改述为“确定性 bit-flip 算法”。
