# 17 补充实验：收敛图到底说明什么

## S.1.1：两个单次轨迹

设置 N=J=1000、K=7、\(g=s=.3\)，画像近似均衡。Q 由单属性和循环双属性块构成。

**扰动初始化例子**：前三轮 Q 改变 2246、275、11 个元素，第四轮为0；之后题目端点仍有小幅变化。

**完全随机初始化例子**：前四轮改变 2312、1746、400、141 个元素，第五轮起 Q 稳定，最终 Q 与真值相差一个列置换。

两者说明可能快速到达好的结构，但一个轨迹不能证明所有初始值都如此。

## Q 不动，是否全模型收敛

不一定。即使 Q 不变：

- A 仍可能变化；
- 概率端点仍可能变化；
- 运行平均仍可能变化；
- 随机抽样可能暂时未越过概率很小的跳转。

因此不能只数 Q 改动就宣称所有参数都达到同一停止精度。

## 重建的是理想反应，而非预测准确率

作者比较的是无噪声理想矩阵与观测/重建矩阵的差异。第一个例子中：

\[
\text{观测噪声错误率}=.2995,\qquad
\text{理想矩阵重建错误率}=5.21\times10^{-5}.
\]

第二个例子的重建错误率为 \(7.20\times10^{-5}\)。

这些数说明估计结构能从噪声中恢复理想模式，但它们不是 held-out 答题错误率。实际作答有猜测与失误，不能要求预测噪声反应也接近百分之百准确。

## S.1.2：200 次、固定十轮

每次把真实 Q 大约三分之一元素扰动后作为起点，运行恰好十轮。作者报告十轮后200个数据集全部恢复 Q。

重要限定：

- 初始值使用了真 Q 的扰动，不是纯 response-only 初始化；
- 运行十轮是该实验设计，不是通用充分收敛定理；
- 此处是固定尺寸和参数下的经验结果，不是高维全局收敛证明。

## S.1.3：强两参数信号

在 N=2400、J=1200、K=3 的 G-DINA 数据中，提高最高阶交互相对其他效应的贡献。图示一阶段两参数拟合就准确恢复 Q 和 A。

其意义与 Theorem 3 对应：结构可能恢复得很好，即使低组内部真概率被简化。图中同时展示真、估计题目参数，恰好提醒“结构正确”与“全部概率参数正确”要区分。
