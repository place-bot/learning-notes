# 16 TIMSS：真实测量中如何使用专家结构

## 数据与属性

本文分析 TIMSS 2011 奥地利四年级数学数据：N=1010、J=47、K=9。数据来自 R 包 CDM 所收录的数据集。九属性由内容领域与认知过程交叉形成：

| | Applying | Knowing | Reasoning |
| --- | --- | --- | --- |
| Data | DA | DK | DR |
| Geometry | GA | GK | GR |
| Number | NA | NK | NR |

这是本文真实应用。不能混写成 FrcSub 或 ECPE。

## 51.73% 缺失如何处理

不同学生只回答测评题库的部分题，产生计划性缺失。作者在可忽略缺失假设下，仅对观测位置 \(\Omega\) 写似然，并用 Supplement Algorithm S.3。

处理缺失的含义是“跳过未观测位置”，不是把它们填0，也不是拿模型自己预测的值当真实反应重新计入似然。

## 专家 Q 不只是无约束起点

原始 \(47\times9\) Q 每题只标一个属性。作者：

1. 用专家 Q 初始化；
2. 选择九道锚题，其 Q 行构成 \(I_9\)；
3. 在迭代中固定这些锚题行，以保持属性名称；
4. 估计其他题目结构与所有学生画像。

因此这个实例并非所有 Q 行都完全自由的 response-only 学习。初始化与固定锚点必须分别交代。

## 两参数与多参数怎么选

先做两参数拟合，再做第二阶段多参数拟合，以 BIC 比较。论文报告两参数模型 BIC 更小，因此实际解释的是两参数结果。

“较小 BIC”是惩罚拟合指标上的偏好；这里没有报告 held-out RMSE/AUC 比较，也没有已知学生真画像的分类准确率。

## Q 的变化

有十道题变为多属性题，原来标注的属性在这十题中仍被保留。新增联系常集中于同一内容或认知领域。

例如 M051001（Soccer tournament），估计支持包括 DK、NA、NK、NR。原文讨论重点是 Number 领域三个属性均有关联，但不能据此漏掉表中的 DK。

这是对题目要求的模型解释，不能只凭增加连接就断言专家标注错误或新增连接具有因果意义。

## 学生画像的结果同样重要

按估计 A 计算领域内平均掌握率：

| 内容领域 | 平均掌握率 |
| --- | ---: |
| Data | 50.63% |
| Geometry | 48.12% |
| Number | 46.50% |

| 认知过程 | 平均掌握率 |
| --- | ---: |
| Applying | 50.83% |
| Knowing | 49.17% |
| Reasoning | 45.25% |

例如 Data 是 DA、DK、DR 三列掌握率的平均，而不是“学生同时掌握这三个属性”的比例。

估计 A 中，NA、NK、NR 的两两相关为 .23、.24、.20，GA 与 NA 为 .28。作者将这些联系与 Q 中常一起出现的属性对照解释。这里是同一拟合结果的关联结构，不是对因果关系或学生真值的外部验证。

## 对实际软件展示的启发

一个测量示例应同时呈现：专家输入与固定约束、最终 Q、学生画像、题目参数、拟合依据，以及缺失如何处理。只展示 Q 热图会遗漏 joint estimation 的重要目的。
