## 阅读范围与证据层级

1. 主文模型、Assumptions 1–5、Theorems 1–3、Algorithm 1、Tables 1–4 与应用讨论。
2. Supplement S.1全部实验、S.2证明及技术引理、S.3两项附加算法。
3. 本站独立代数推导与小规模计算检查，均在相应章节标明。
4. 数学记号或论证衔接未解决处列入[核对记录](19-source-audit.md)，不冒称最终期刊版本已经勘误或作者程序已经验证。

本站没有重新发布论文全文，也没有把作者实验表全部复制为自己的复现结果。需要精确引用或重新实现时，请回到所用版本的原文并记录版本。
