# 01 为什么要直接估计学生画像

## 一个具体任务

有 \(N=1000\) 名学生、\(J=1000\) 道题、\(K=10\) 个属性。观测的是百万个对错反应。希望得到：

- 每名学生掌握哪些属性：\(A\)，大小 \(1000\times10\)；
- 每道题要求哪些属性：\(Q\)，大小 \(1000\times10\)；
- 题目噪声参数：例如 DINA 的猜测与失误。

不是只估计 Q。学生画像本身就是测量输出。

传统混合模型把学生画像看成随机变量；每名学生有 \(2^{10}=1024\) 种候选画像。\(K=15\) 时是 32768 种。若每次 EM 都对每人逐一计算全部画像的后验权重，计算迅速变重。

## 作者改变的是估计视角

把 \(a_i\) 当作固定但未知的参数，与 Q、题目参数一起优化。这不等于说现实中学生没有总体分布，而是当前估计目标不需要为 \(2^K\) 个画像再估计一组混合比例。

这种改变有代价：未知参数个数随 N 增长。只让 N 增长而让 J 固定，每个学生的信息并不会无限增加。因此不能直接套普通固定维 MLE 的一致性结论。

## 为什么同时需要大 N 和大 J

固定题目结构时，一名学生有 J 个反应帮助判断其画像；固定学生画像时，一道题有 N 个反应帮助判断其结构和参数。

所以：

\[
\text{更多题目}\longrightarrow\text{更多个人测量信息},\qquad
\text{更多学生}\longrightarrow\text{更多题目校准信息}.
\]

但是“更多”必须是有用信息：大量重复无区分度题目不能替代区分信号；没有某些画像的学生样本也可能无法区分 Q 行。

## 三重渐近，不是任意增长

作者允许 N、J、K 同时增长，但附加增长速率条件。尤其要求所有画像都有足够样本，意味着 K 不能不受限制地增长。这与“能计算 K=15 的例子”是不同层次的陈述。

## 本文与前后文献的分工
