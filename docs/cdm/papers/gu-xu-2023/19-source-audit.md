## 需要继续核实，而非一句“笔误”解决的地方

### 1. Theorem 1(a) 的概率对象

主文用 \(p(\widehat Q,\widehat A,\Theta^0)\)，证明首先得到的是估计分组下真概率均值 \(\bar P^{\widehat Z}\)。二者一般不同；不能在解释中直接等同。若要独立重证原定理，需要补上对象转换与相应条件。

### 2. 全部候选结构的计数

部分 union bound 使用 \((2^K)^N\)，但 Q 也未知。若 Z 包含联合 A、Q，应说明不同 Q 诱导的局部分组如何被计入。粗略联合计数含额外 \(2^{JK}\)；也可能通过更精细分组论证改进。这里保留问题，不假装一个简短说明就验证了原速率。

### 3. 增长条件的记号

主文 Theorem 1 与补充 Proposition/Lemma 中出现含 \(2^K\)、\(2^{K_0}\) 的不同写法，以及不同的 \(\sqrt M\) 因子。引用主文时按主文陈述；从补充材料独立推速率时必须重新核对哪一个是实际所需条件。

### 4. 多参数证明中的顺序与支持

多参数局部概率可能有复杂顺序；均值比较使用的方向、零支持候选如何排除，以及行支持上界的 oracle 性质，都不应从证明中略去。

### 5. S.2.3 玩具例子的候选分组

“\(Z\ne Z^0\)”不必意味着不同输出分组，例如共同列置换就不改变模型。例子用于理解强组间信号与弱组内变化的关系很好，但若要当作对全部候选 Z 的严格证明，需要明确按何种等价类及约束比较。本专题不把它改写成无条件唯一性定理。

## 实验读取方面

- Tables 1–3 表头是 \(2^K,J,N\)，段落有 N、J 顺序不一致；本站按表头解释。
- Table 2 小 J 条件 A 整行准确率小于1，不能用旁边笼统文字概括成全部完美恢复。
- Table 3 的 1.000 是舍入后的行/元素准确率，不等于整矩阵完全恢复次数200/200。
- S.1 的理想矩阵重建误差不是测试集反应预测误差。

## 如何继续手推

先完成不依赖这些疑点的部分：Bernoulli MLE、剖面 KL 恒等式、最优性夹逼、混组损失、布尔结构引理、Gibbs 对数赔率。再处理复杂的统一计数与渐近条件。这样能准确区分“我已推完”与“这里仍需核实”。
