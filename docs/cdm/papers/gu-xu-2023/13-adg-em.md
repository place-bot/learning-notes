# 13 ADG-EM：逐轮到底做什么

## 输入与状态

输入 R 和属性数 K；维护二值 A、Q，题目端点 \(\theta^+,\theta^-\)，以及 A 的运行平均 \(A^{\mathrm{ave}}\)。

初始化是算法的一部分；不同初始值可能到达不同区域。文章的全局估计定理不能保证消除这种计算差异。

## 一轮操作

1. 用当前题目端点计算所有 \(\psi_{ij}\)。
2. 固定 Q，逐坐标对 A 做 C 轮 Gibbs 扫描。
3. 把本轮 A 样本均值并入跨迭代运行平均。
4. 固定当前 A，逐坐标对 Q 做 C 轮扫描。
5. 本轮 Q 样本按多数票二值化。
6. 用软理想反应权重更新题目端点。

条件概率应结合[前章符号推导](12-gibbs.md)读取，不能机械复制底本显示式。

## A 平均与 Q 平均不一样

主文 Algorithm 1：

\[
A^{\mathrm{ave},t}
=(1-t^{-1})A^{\mathrm{ave},t-1}
+t^{-1}\frac1C\sum_{c=1}^CA^{t,c},
\]

\[
Q^t=1\left(\frac1C\sum_{c=1}^CQ^{t,c}>1/2\right).
\]

前者跨迭代平滑；后者只有当前轮 C 个样本的多数票。若所有 C 相同，上式 A 平均就是前 t 轮均值的平均。

最终 A 再按 \(>1/2\) 输出二值画像。平均值位于 [0,1] 是计算状态，不是本文换用了 partial-mastery 模型。

## 题目更新

主文使用

\[
w_{ij}=\prod_k(A^{\mathrm{ave}}_{ik})^{q_{jk}},
\]

\[
\theta_j^+=\frac{\sum_i r_{ij}w_{ij}}{\sum_iw_{ij}},\qquad
\theta_j^-=\frac{\sum_i r_{ij}(1-w_{ij})}{\sum_i(1-w_{ij})}.
\]

这些是加权 Bernoulli 对数似然的最大值，求导方式与第三章相同。

但一般

\[
E\left[\prod_k A_{ik}^{q_{jk}}\mid R\right]
\ne \prod_k E[A_{ik}\mid R]^{q_{jk}}.
\]

因此不能把这个乘积均值步骤称为精确 E 步。举例：后验只在 00 与 11 各一半，则两个边际均值均为 .5，其乘积 .25，但两属性同时掌握概率是 .5。

## 为什么快：避开指数枚举

每轮需要更新约 \((N+J)K\) 个二值坐标，而非逐人枚举全部 \(2^K\) 个画像。

不过每个 A 坐标的条件概率仍需对题目求和，每个 Q 坐标仍需对学生求和。底本的 \(O((N+J)K)\) 应谨慎理解：它数的是坐标更新次数，不是完整朴素程序的全部算术。

在缓存相关乘积且稠密扫描时，基本工作量通常有 \(O(CNJK)\)；若每个乘积又从头遍历 K，则可多一个 K。稀疏 Q、缓存和向量化会进一步改变实际代价。

## Supplement Algorithm S.2

S.2 将 A 和 Q 都作随机逼近平均并二值化，同时对题目更新作平均；其理想反应由二值状态计算。它不是仅给 Algorithm 1 改一个名称。原伪代码中部分平均变量初始化不完整，写程序时须明确。

## Supplement Algorithm S.3

缺失版本将求和限制到 \(\Omega\)，分母也只统计对应观测项。若某组该题没有观测反应，需要显式处理空分母。

## 该如何报告收敛

至少区分结构是否稳定、端点是否稳定、目标函数轨迹、最大迭代是否触顶。随机算法不必每步提高似然；输出不再变化也不等于已证明全局最优。
