# 09 为什么小概率误差能推出 A、Q 接近

## 1. 先看一道题的混淆表

令 \(N_{ab}\) 表示真理想反应为 a、估计理想反应为 b 的人数：

| | 估计 0 | 估计 1 |
| --- | ---: | ---: |
| 真 0 | \(N_{00}\) | \(N_{01}\) |
| 真 1 | \(N_{10}\) | \(N_{11}\) |

估计高组的 oracle 概率为

\[
\bar\theta_1=
\frac{N_{11}\theta^++N_{01}\theta^-}{N_{11}+N_{01}},
\]

低组同理。把高低两种真概率混在同组，会让至少一部分人的拟合概率偏离真值。

## 2. 加权平方偏差的精确化简

对有 m 个高概率、n 个低概率的组，均值为
\(u=(m\theta^++n\theta^-)/(m+n)\)。令 \(d=\theta^+-\theta^-\)，则

\[
\theta^+-u=\frac{n}{m+n}d,\qquad
\theta^--u=-\frac{m}{m+n}d.
\]

所以

\[
m(\theta^+-u)^2+n(\theta^--u)^2
=\frac{mn}{m+n}d^2.
\]

再用 Pinsker，并利用 \(2mn/(m+n)\ge\min(m,n)\)，得到该题 KL 损失至少

\[
\beta_J\{\min(N_{10},N_{00})+\min(N_{11},N_{01})\}.
\]

因此混组越严重、信号越强，必须付出的似然损失越大。

## 3. 为什么还要固定高低方向

若把两个组整体交换，混组损失仍可能为零。要求高组概率高于低组能够排除这种任意翻转。由两个均值相减可验证：

\[
\bar\theta_1>\bar\theta_0
\iff N_{11}N_{00}>N_{10}N_{01}
\]

（分母非零时）。补充证明据此划分好题与坏题，再用所有画像均有样本及行稀疏性证明坏题占比小。

## 4. 结构引理：单位阵为什么特殊

考虑 K 道题，真 Q 为 \(I_K\)。所有 \(2^K\) 种画像的理想反应正好就是画像本身，因此有 \(2^K\) 个不同输出。

假设另一个 \(K\times K\) 二值矩阵 B 也能产生全部不同输出。若它缺少某一行 \(e_k\)，则对画像 0 与 \(e_k\)：

- 任何非空且不等于 \(e_k\) 的要求，都无法被二者满足；
- 空要求则被二者同时满足。

故两画像输出相同，矛盾。因此 B 必须含全部 \(e_1,\ldots,e_K\)。它总共仅 K 行，所以 B 是单位阵的排列。

这一步把任意画像重标记，限制为共同属性置换。

## 5. A 对齐后，不同 Q 必有区分画像

设要求集合 S 与 T 不同。若有 \(k\in S\setminus T\)，构造画像：T 内属性均为 1，k 为 0，其余任意。它满足 T 而不满足 S。若差集在另一方向，交换角色。

所以在全部画像都有代表时，两种不同题目要求不可能对所有人产生相同 AND 输出。

## 6. 从精确引理到误差比例

原证明将重复单属性题组织成多块单位阵，并把样本组织成包含各画像的块。低总损失意味着大部分块不能大量违反上面的结构关系。随后先确定共同属性置换，再分别控制：

- 错误学生画像必须在足够多单属性题上付出代价，分母出现 \(\delta_J\)；
- 错误 Q 行必须在足够多区分画像学生上付出代价，分母出现 \(p_N\)。

这里“组块—筛除坏块—共同置换—计数”的完整渐近步骤在原文 S.2.1 Steps 5–7；上面的精确结构引理不能单独替代全部速率证明。
