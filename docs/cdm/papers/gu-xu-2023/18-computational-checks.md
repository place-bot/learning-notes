# 18 可运行核验：用很小的例子检查关键等式

本站提供 [Python 检查脚本](https://github.com/place-bot/Psychometrics-and-R-Shiny/blob/main/tools/gu_xu_2023_joint_mle_check.py)，仅用标准库：

```bash
python3 tools/gu_xu_2023_joint_mle_check.py
```

它不是作者官方 ADG-EM，也不声称复现主文200次模拟。它的任务是让读者能独立检查推导，避免照着显示公式写出反向概率。

本次实际运行通过：32,768 项 Gibbs 对数赔率比较、256 项剖面恒等式、49 项混组损失恒等式，以及 K=2、3 的全部布尔矩阵检查（单射矩阵分别为2、6个）。

## 检查一：所有小矩阵的 Gibbs 对数赔率

枚举 \(N=J=K=2\) 的全部二值 A、Q、R。对每个坐标：

1. 强制它为0，计算完整联合对数似然；
2. 强制它为1，再计算完整联合对数似然；
3. 相减；
4. 与第12章简化公式比较。

这检查的不只是一个容易的例子，而是小规模下所有坐标配置。题目端点使用非对称值，避免只在对称参数下碰巧相等。

## 检查二：剖面似然恒等式

构造一组真概率与反应、给定候选局部分组，独立计算：

\[
L-\bar L
\]

与

\[
\sum_{jc}n_{jc}D(\widehat\theta_{jc}\|\bar\theta_{jc})
+\sum_{ij}(r_{ij}-P^0_{ij})\logit(\bar\theta_{j,z_{ij}}).
\]

两者应在浮点误差范围内相同。若错把 \(\bar L\) 当成 \(E[L]\)，就不会得到同一理论恒等式。

## 检查三：布尔锚定引理

枚举 K=2、3 的全部 \(K\times K\) 二值 Q，计算全部画像的理想反应。能够产生 \(2^K\) 个不同输出的矩阵应恰好是 K! 个置换矩阵。

再枚举所有不同 Q 行，验证在固定全部画像下，必有一个区分画像。

这证明不了任意 K 的结论，但与第9章任意 K 的数学证明相互核验。

## 检查四：乘积均值不是联合期望

令 A 的分布仅在 00 和 11 各一半：

\[
E[A_1A_2]=.5,\qquad E[A_1]E[A_2]=.25.
\]

这个反例防止把 ADG-EM 的软乘积写成不加条件的精确 E 步。

## 不能由测试通过推出什么

- 不能证明所有渐近速率；
- 不能验证作者未获得的实际源码；
- 不能说明本站重跑了 Table 1–3；
- 不能证明随机算法必然得到全局最大值。
