## Source Boundary

This topic checks the official PDF of the main paper page by page, and checks the 2017 comments and responses. Code page check R/C++ source code for the current CRAN `GDINA` 2.9.12.

The following material has not been republished:

- Main paper PDF;
- 536 people original response matrix;
-Original author Ox source code.

The Python script on this site is an independent teaching implementation, Table 1 is an accurate check, and Monte Carlo is an algorithm-level reproduction.
