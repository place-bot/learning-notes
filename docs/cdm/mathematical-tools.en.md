## How to pronounce

These documents are not suitable for hard reading chapter by chapter. A more effective way is to make excerpts around subsequent proof questions:

- Which matrix column ranks or Kruskal ranks are required by the Kruskal condition.
- How does tensor decomposition uniqueness translate into parameter uniqueness of latent class model.
- How graphical model languages express conditional independence and latent variable structures.
