# 3. Traditional normal Ogive model

## 3.1 Why is the normal Ogive model needed?

The normal ogive model contains the same parameters as the corresponding logistic model, but the item characteristic curve is generated by a different function.

**Historical Background:**

- Based on cumulative normal distribution
- Easier to understand before the computer age
- Important links with Classical Test Theory

**Why is it called "Ogive"? **

Ogive is another name for the cumulative curve, which is shaped like an elongated S and is often used to describe the cumulative distribution function in statistics.

## 3.2 Form

The normal ogive model expresses the ICC as the proportion of cases below a certain standard score \(z_{is}\):

\[
P(X_{is} = 1) = \int_{-\infty}^{z_{is}} \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{t^2}{2}\right)dt \tag{4.7}
\]

Among them:

- The integral symbol represents the distribution area from \(-\infty\) to \(z_{is}\)
- \(\pi\) = constant 3.14159...
- Formula contains normal density function

**Popular understanding:**

This is asking: "In the standard normal distribution, what proportion of values are less than \(z_{is}\)?"

If \(z_{is} = 0\), the answer is 50%
If \(z_{is} = 1\), the answer is about 84%
If \(z_{is} = -1\), the answer is about 16%

## 3.3 Two-parameter normal Ogive model

### 3.3.1 Parameter structure

The two-parameter normal ogive model has the same parameter structure as the 2PL model:

\[
z_{is} = \alpha_i(\theta_s - \beta_i) \tag{4.8}
\]

Complete model:

\[
P(X_{is} = 1|\theta_s,\beta_i,\alpha_i) = \int_{-\infty}^{\alpha_i(\theta_s - \beta_i)} \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{t^2}{2}\right)dt \tag{4.9}
\]

### 3.3.2 Calculation example

**Example 1:** If \(\alpha_i = 1.0\), \(\theta_s = 2.00\), \(\beta_i = 1.00\)

Calculation steps:

1. \(z_{is} = 1.0 \times (2.00 - 1.00) = 1.00\)
2. Check the normal distribution table: \(\Phi(1.00) = 0.8413\)
3. Therefore, the item success probability is 0.8413

**Actual meaning:**
Students whose ability is 1 standard deviation higher than difficulty have an 84% chance of answering correctly!

**Example 2:** If the parameter combination produces \(z_{is} = -1.50\)

The probability obtained from the cumulative normal distribution is 0.0668

**Actual meaning:**
Students whose ability is 1.5 standard deviations below the difficulty level only have a 6.7% chance of answering the question correctly.

### 3.3.3 Connection with Classical Test Theory

important relationship

If trait levels show a normal distribution and the data fit the two-parameter normal ogive model, Lord and Novick (1968) showed that the following relationship exists:

**1. The relationship between discrimination and bi-column correlation: **

\[
\alpha_i \cong \frac{r_{bis}}{\sqrt{1 - r^2_{bis}}} \tag{4.10}
\]

Meaning:

- item discrimination and bi-column correlation are monotonically increasing
- Selecting items through IRTItem discrimination is similar to selecting items through bi-column correlation.

**Specific example:**

- If \(r_{bis} = 0.5\), then \(\alpha \approx 0.58\)
- If \(r_{bis} = 0.7\), then \(\alpha \approx 0.98\)

**2. The relationship between difficulty and p-value:**

First convert \(p_i\) to normal bias \(z_i\):

- If \(p_i = 0.84\), then \(z_i = -1.00\) (note: it is the upper side area)

Then:

\[
\beta_i \cong \frac{z_i}{r_{bis}} \tag{4.11}
\]

Meaning:

- The ranking of items by p value is somewhat different from the ranking of IRTitem difficulty
- Using IRTitem difficulty may result in selecting items with different values from Classical Test Theoryp

**Why is it different? **

CTT only considers the pass rate, while IRT also considers the distinguishing ability of items!

## 3.4 Three-parameter normal Ogive model

Similar to the 3PL model, the following asymptote parameters can be added:

\[
P(X_{is} = 1|\theta_s,\beta_i,\alpha_i,\gamma_i) = \gamma_i + (1-\gamma_i)\int_{-\infty}^{\alpha_i(\theta_s - \beta_i)} \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{t^2}{2}\right)dt \tag{4.12}
\]

As with the 3PL model, the itemdifficulty parameter represents the inflection point of the ICC, but not the .50 threshold at the trait level.

## 3.5 Comparison between logistic and normal Ogive models

### 3.5.1 Similarity of probability prediction

Let's compare the two previous examples:

**Example 1 (\(z_{is} = 1.0\)):**

- Normal ogive: P = 0.8413
- Logistic model (with 1.7 multiplier): P = 0.8455
- Difference: 0.0042

**Example 2 (\(z_{is} = -1.5\)):**

- Normal ogive: P = 0.0668
- Logistic model (with 1.7 multiplier): P = 0.0724
- Difference: 0.0056

**Conclusion:** The predictions of both models are almost identical!

1.7 scaling factor

To make the logistic model similar to the normal ogive model, you need to include a multiplier of 1.7 in the exponent.

This factor comes from the ratio of the two distribution variances: \(\pi^2/3 \approx 3.29\), \(\sqrt{3.29/1.13} \approx 1.7\)

**Memory Tips:** The logical distribution is "fat" than the normal distribution and requires 1.7 times scaling to match!

### 3.5.3 Select suggestions

**Should I choose the logistic or normal ogive model? **

Since both model predictions are almost identical, the choice is mainly based on:

- **Easy to calculate** → Logic model (no integration required)
- **Theory required** → Normal ogive model (link to CTT)
- **Software Support** → Modern software supports multiple logical models

**Actual advice:**

Unless there are special reasons (such as needing to interface with CTT parameters), the logistic model is generally chosen because:
1. Calculation is simpler
2. Parameter explanation is more intuitive
3. Wider software support
