# 8. Summary

This chapter introduces a variety of IRT models suitable for binary data:

## 8.1 Single-dimensional model

**Rasch model**: the simplest, only difficulty parameter

- Advantages: fewer parameters, clear explanation, good scale properties
- Disadvantages: There are many assumptions and restrictions, and the fit may not be good.

**2PL model**: Add discrimination parameter

- Advantages: more flexible, better fitting
- Disadvantages: many parameters, large samples required

**3PL model**: Add guessing parameter

- Advantages: more reasonable handling of multiple-choice questions
- Disadvantages: parameter estimation is difficult and requires a large sample

**Special models**: LLTM, velocity model, non-parametric model, etc.

- Extensions for specific situations

## 8.2 Multidimensional model

**Exploratory Model**: Discover underlying dimensions
- No default structure
- Data driven

**Confirmatory Model**: Test theoretical hypotheses
- theory driven
- Hypothesis testing

**Special structure**: learning model, hybrid model, etc.
- Handle complex situations

## 8.3 Select suggestions

Model selection depends on:

- Measurement purpose
- Theoretical assumptions
- Data characteristics
- sample size
- Practical considerations

**Decision Process:**

1. Try the Rasch model first
2. If the fit is not good, consider 2PL
3. If it’s a multiple-choice question, consider 3PL
4. If you suspect multi-dimensionality, perform dimensional analysis
5. Choose an appropriate extension model based on theory

core concept

The study of IRT models for binary data remains an active area in psychometric methods.
These developments have expanded the scope of IRT, enabling it to handle increasingly complex measurement situations.

Choosing the right model is not the goal, it is to better understand the construct we want to measure!
