# 10. Concept Supplement 5: Examples showing why the “partial credit model” applies to partially correct items

In actual achievement tests, many items cannot be simply judged as "right" or "wrong". These items often have the possibility of being **partially correct**, or contain multiple evaluation dimensions. If this type of item is forced to use binary scoring, not only will information be lost, but it may also affect the model fit effect and participantability estimate.

The following are a few typical examples of why this type of item is suitable for modeling using **partial credit model (PCM)** or **generalized partial credit model (GPCM)**:

## 10.1 Example 1: Mathematical process questions

**item:** Simplified expression \(\frac{2x^2 + 4x}{2x}\)

**Rating method:**

|Answer content|score|explain|
| --- | --- | --- |
| \(\frac{2(x+2)}{2x}\) | 1 |Shows factoring, but does not completely simplify|
| \(x + 2\) | 2 |Complete factorization and reduction correctly|
| \(x\) | 0 |Simplification error|

This question has a clear partially correct path, and using the GPCM model can better model the answering performance at different ability levels.

## 10.2 Example 2: Reading comprehension questions

**item:** After reading the passage, answer: "What is the author's point of view? Please provide two supporting evidence."

**Rating method:**

|Answer situation|score|
| --- | --- |
|Makes an opinion but lacks evidence| 1 |
|Make a point + a supporting evidence| 2 |
|Clear point of view + two reasonable evidences| 3 |
|Answer irrelevant or wrong| 0 |

This question tests the ability to integrate information, and the score has a hierarchical structure, which is very suitable for using PCM modeling.

## 10.3 Example 3: Scoring a Writing Task

**item:** Write a paragraph explaining whether you agree with the view that "effort is more important than talent".

The scoring basis may include "completeness of expression", "language structure", "logic", etc., using a 0-5 point scoring system. This type of item inherently has ordered multi-level characteristics, and is most suitable to be characterized using the **Grade Response Model (GRM)** or **PCM**.

Together, these examples illustrate that when items allow partial scoring or multi-level scoring, the traditional binary IRT model is no longer applicable. At this time, a multi-category model, such as PCM or GPCM, should be used to more accurately describe the relationship between response behavior and ability.
