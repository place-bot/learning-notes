# 18. Model selection

## 18.1 Basic questions

Given the large number of potentially applicable models, how should researchers select models to fit real-world data sets?

## 18.2 Key considerations

### 18.2.1 Data type

**Reaction Category Nature:**

- If the reaction categories are not ordered, then NRM is the only suitable option

**item discrimination difference:**

- If the item is suspected to have different degrees of distinction
- As may be revealed by preliminary factor analysis
- then the GRM or Muraki (1990; 1992) model is automatically more suitable than any Rasch-based model such as RSM or PCM

### 18.2.2 Response format consistency

**Assessment scale requirements:**

- If the measurement does not use the same rating scale for each item
- Then RSM is not applicable (unless item groups are analyzed separately)

## 18.3 Current status of statistical model comparison

### 18.3.1 Current Limitations

As discussed in Chapter 9, the science of statistical model comparisons in IRT is relatively lacking, especially compared to structural equation models.

### 18.3.2 Existing statistical methods

**1. Log-likelihood comparison:**

- Some researchers use the model-data log-likelihood as a tool to compare different IRT models
- Example: Rost (1988)

**2. Ideal Observer Statistical Technique:**

- proposed by Levine et al. (1992)
- offers great promise for determining whether the two models indeed differ in their fit to the actual data

### 18.3.3 Empirical research result

**Findings of Maydeu-Olivares, Drasgow and Mead (1994):**

When applying the ideal observer technique to actual multinomial data, little fit difference was found between the GRM and the extended PCM model of Thissen and Steinberg (1986).

## 18.4 Practical model selection considerations

Decisions based on practical considerations in the absence of a statistical magic wand:

**1. Number of parameter estimates:**
A model with fewer parameters is better than a model with more parameters because, generally speaking, the sample size required for estimation will be smaller.

**2. Convenience of scoring:**
In Rasch models (such as PCM), the raw scale score is a sufficient statistic at the trait level.

**3. Philosophical perspective:**

- For some researchers: it is inappropriate to require test items to have equal discrimination → choose GRM
- Other researchers: may prefer RSM model with graded difficulty
- Attitude researchers: may find RSM very attractive

**4. Program Availability:**
It goes without saying that a model can only be fitted if appropriate and available procedures are available.

## 18.5 Actual decision-making process

Decision tree suggestions

1. First determine the data characteristics (ordered vs. unordered, same format vs. mixed format)
2. Consider sample size and parameter estimation requirements
3. Evaluate the reasonableness of the assumption that discrimination is equal
4. Consider ease of scoring and interpretation
5. Check software availability

## 18.6 Summary

Model selection requires comprehensive consideration of data characteristics, theoretical assumptions, practical needs, and technical limitations. No one model is suitable for all situations, and informed choices need to be made based on specific research objectives and data characteristics.
