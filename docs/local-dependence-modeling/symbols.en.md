# Symbols and abbreviations

## Core notation

| Symbol | Meaning |
| --- | --- |
| \(Q=\{q_1,\ldots,q_J\}\) | Binary-item/problem domain |
| \(X_i\) | Observed binary response |
| \(K\subseteq Q\) | Knowledge/mastery state |
| \(\mathcal K\) | Structure of allowable knowledge states |
| \(2^Q\) | Power set containing all \(2^J\) patterns |
| \(K^O\) | Outer fringe: items legally addable to \(K\) in one step |
| \(\theta,\Theta\) | Unidimensional and multidimensional latent traits |
| \(\pi(K\mid\theta)\) | State response function (SRF) |
| \(P(X\mid K)\) | \(g\)-process conditional probability |
| \(\eta_i,\beta_i\) | Lucky-guess and careless-error/slip rates |
| \(a_i,b_i,c_i,d_i\) | Discrimination, difficulty, guessing, and slipping parameters |

## Abbreviations

| Abbreviation | Expansion |
| --- | --- |
| LI / LD | Local independence / local dependence |
| SLD / ULD | Surface / underlying local dependence |
| RD / OD / CD | Response / order / combination dependence |
| LND | Local nonnegative dependence |
| WLIE | Weak local independence in expectation |
| IRT / KST / CDA | Item response theory / knowledge space theory / cognitive diagnostic assessment |
| IRF / SRF | Item response function / state response function |
| GLI | Generalized local independence |
| BLIM / Theta-BLIM | Basic local independence model / latent-trait extension |
| SLM / Theta-SLM | Simple learning model / latent-trait extension |
| LKS | Logistic knowledge structure |
| PCM | Partial credit model |
| 1PLAG | One-parameter logistic ability-based guessing |

The three central probabilities are linked by

\[
P(X\mid\theta)=\sum_{K\in\mathcal K}P(X\mid K)\pi(K\mid\theta).
\]
