# 参数解释与可识别性

## 为什么先检查边缘IRF

联合模型加入依赖后，项目参数是否仍有传统IRT含义，取决于边缘IRF能否再现。

若联合分布满足：

\[
\sum_{\boldsymbol x_{-i}}
P(\boldsymbol X=\boldsymbol x\mid\theta)
=P(X_i=x_i\mid\theta)
\]

且右边仍是原先的2PL/4PL，项目难度和区分度可继续按传统方式解释。若不满足，联合交互改变了边缘曲线，
同名参数的含义也随模型而变。

## Table A中的\(\Theta\)-SLM

对第一题：

\[
P(X_1=1\mid\theta)
=
\eta_1+(1-\beta_1-\eta_1)
\pi(K_1=1\mid\theta).
\tag{40a}
\]

若\(\pi(K_1=1\mid\theta)\)是2PL，这就是标准4PL，因此第一题边缘可再现。

第二题则为：

\[
P(X_2=1\mid\theta)
=
\eta_2+(1-\beta_2-\eta_2)
\pi(K_1=1\mid\theta)
\pi(K_2=1\mid\theta).
\tag{41a}
\]

因为掌握第二题必须先掌握第一题，第二题边缘曲线包含两个转移概率的乘积，不再是普通单题2PL。

这里\(b_2\)的正确解释是：

> 在已经进入前一状态、也就是已掌握\(q_1\)的人中，有一半进一步掌握\(q_2\)时的能力位置。

它不是无条件总体中第二题50%成功位置。

## Table A中的LKS

LKS是divide-by-total模型。状态概率共同使用分母，所以改变一个状态的难度会改变所有状态概率。

难度参数更接近：

> 低一级状态与高一级状态取得相同相对权重的位置。

这与PCM步难度的解释相似，而不是独立二分题难度。

## Table B中的虚拟题解释

对同等信息结构，两个边缘IRF分别为：

\[
P(X_1=1\mid\theta)
=
\eta_1+(1-\beta_1-\eta_1)
\frac{e^{2(\theta-\bar b_{12})}}
{1+e^{2(\theta-\bar b_{12})}},
\tag{42}
\]

\[
P(X_2=1\mid\theta)
=
\eta_2+(1-\beta_2-\eta_2)
\frac{e^{2(\theta-\bar b_{12})}}
{1+e^{2(\theta-\bar b_{12})}}.
\tag{43}
\]

两题共享一个难度为\(\bar b_{12}\)、区分度为2的虚拟潜在题，但可以拥有不同的\(\eta_i,\beta_i\)。

## left-side-added是什么意思

传统2PL先给掌握概率：

\[
\pi_i(\theta)=P(K_i=1\mid\theta).
\]

猜测和失误在左侧观测模型中加上：

\[
P(X_i=1\mid\theta)
=\eta_i+(1-\eta_i-\beta_i)\pi_i(\theta).
\]

因此\(\eta_i,\beta_i\)称为left-side-added参数：它们属于\(K\to X\)的测量/误差层，而不是\(\theta\to K\)的掌握层。

## 二题为什么不可识别

一个二乘二列联表有4格，但总和固定为1，所以只有：

\[
4-1=3
\]

个独立信息量。

若每题需要四个参数：

\[
(a_i,b_i,\eta_i,\beta_i),
\]

两题共有8个参数，远多于3个独立格概率。仅凭该表不可能唯一恢复全部参数。

## 作者给出的粗略计数

### 两两分析

若有\(n\)题，每个题对提供3个独立格条件，一共有：

\[
3\binom n2=\frac{3n(n-1)}2.
\]

每题4参数，共\(4n\)。粗略必要计数为：

\[
\frac{3n(n-1)}2\ge4n.
\]

最小整数解为\(n=4\)。

### 整体知识结构

完整\(n\)题反应分布有：

\[
2^n-1
\]

个独立模式概率。因此粗略要求：

\[
2^n-1\ge4n,
\]

最小整数解为\(n=5\)。

## 为什么这还不是可识别性证明

“数据自由度不少于参数数”只是必要的维数检查，不保证映射是一一对应。仍可能有：

- 标签交换；
- 不同结构产生相同分布；
- 参数只通过乘积或和出现；
- 边界参数造成退化；
- 某些结构特定的对称性。

作者明确指出：KST本身的可识别性已有较多研究，但一般KST-IRT可识别性仍是开放问题。

## 实际建模的最低检查

1. 明确哪些参数属于SRF，哪些属于\(g\)-过程。
2. 检查结构中每个状态是否能由数据区分。
3. 不要只靠参数数量小于格数判断可识别。
4. 比较不同初值是否收敛到等价解。
5. 用模拟数据验证参数恢复与结构恢复。
6. 报告结构约束是理论指定还是数据搜索得到。
