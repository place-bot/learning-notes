# 新模型方向与全文结论

## 3.2.3不是完整模型，而是分类表中的空位

作者指出Table 1和Table 2仍有许多逻辑上可定义、但文献中尚未系统研究的单元格。通过选择不同结构、过程和条件概率约束，
可以产生新的模型家族。本文只提出三个方向，没有给出完整估计算法或经验验证。

## 方向一：ULD可以叠加在任意结构上

ULD/trait dependence作用于SRF：

\[
\pi(K\mid\Theta),
\qquad
\Theta=(\theta,u_1,u_2,\ldots).
\]

确定性或概率性LD的区别来自结构是否为幂集。因此可同时使用：

\[
\boxed{\mathcal K\subsetneq2^Q}
+
\boxed{\pi(K\mid\theta,u_t)}.
\]

结构仍排除不合法状态，多维潜变量只改变合法状态之间的概率。结构依赖和遗漏特质依赖不必二选一。

## 方向二：把RD、OD、CD式约束放进确定性结构

概率性LD中的交互作用发生在SRF，不发生在支持集。因此可写：

\[
\pi(K\mid\theta)
\propto
\exp\{f_{base}(K,\theta)+\gamma h(K)\},
\qquad K\in\mathcal K,
\]

同时维持：

\[
\pi(K\mid\theta)=0,
\qquad K\notin\mathcal K.
\]

这样可以得到“确定性结构 + 概率性交互”的混合家族。

## 方向三：能力相关\(g\)-过程

固定\(g\)-过程假定：

\[
P(X\mid K,\theta)=P(X\mid K).
\]

作者建议让猜测和失误随能力变化：

\[
\eta_i(\theta)
=
\frac1{1+\exp(\widetilde\eta_i-\theta)},
\]

\[
\beta_i(\theta)
=
\frac1{1+\exp(\theta-\widetilde\beta_i)}.
\]

因此：

\[
\theta\uparrow
\Longrightarrow
\eta_i(\theta)\uparrow,
\quad
\beta_i(\theta)\downarrow.
\]

同一离散知识状态内，高能力者仍可能更会排除选项、更少粗心。此时：

\[
X\not\!\perp\theta\mid K.
\]

但参数极限和可识别性需要谨慎：若把\(\eta\)理解成纯随机猜测，高能力时趋近1未必合理；它更适合解释为未完整掌握下的能力相关成功。

## 全文总分类

文章用两个基本对象和两种运算统一LD模型：

| 类别 | 内容 |
| --- | --- |
| 基本对象1 | structure：允许哪些状态 |
| 基本对象2 | process：状态之间怎样概率映射 |
| 运算1 | factorization：联合概率怎样分解 |
| 运算2 | reparameterization：概率采用何种链接和kernel |

这套语言用来比较KST、CDA与IRT，而不是按学派名称直接判断模型性质。

## 概率性与确定性机制并不互斥

### 概率性LD

\[
\mathcal K=2^Q.
\]

全部模式允许；依赖由SRF/\(p\)-过程产生。

### 确定性LD

\[
\mathcal K\subsetneq2^Q.
\]

潜在模式受到结构限制；用\(g\)-过程恢复观测层违反。

确定性结构内部仍可有概率交互、多维特质与能力相关误差。因此“结构”和“过程”是可组合的两条轴。

## 各传统模型的位置

| 模型 | 本文的机制解释 |
| --- | --- |
| RD | 用链式法则因子化SRF，再参数化边缘与条件概率 |
| OD、CD | 不因子化，直接用softmax/log-link参数化联合SRF |
| locally dependent latent trait model | 用多阶log-linear交互参数化SRF |
| Bahadur、copula | 引入联合依赖，同时力求保留边缘IRF |
| SLD、boundary mixture copula | 含受限结构成分，因此属于确定性LD |
| KST-IRT | 显式区分结构、SRF与\(g\)-过程 |

所以IRT不自动等于概率性LD；某些IRT模型已经采用结构边界。KST-IRT也不是单一公式，而是一组结构与过程组合。

## 四个应用优势

### 1. 让模型假设匹配现象

若某些配置理论上不应存在，例如技能先决、操作表现或严格层级，确定性结构更自然；若诊断症状只是概率性共现且无明确先决关系，
概率性LD通常更自然。Guttman关系可根据强度与理论被建模为确定或概率；累积多类别题的类别成分则天然有结构约束。

### 2. 解释SLD与ULD参数尺度差异

ULD用连续潜在因子平滑地调节全模式概率；SLD复制成分直接让不一致模式消失。因此中等混合权重就能形成强相关，
而用ULD模仿时可能需要极端载荷或specific-to-general slope ratio。

### 3. 避免用极端参数逼近结构零

若\(p_{01}\approx0\)，完整支持的logistic模型可能需要难度差、斜率或交互参数趋向极端。结构可直接令潜在\(p_{01}=0\)，
再用小猜测/失误解释观察频率。代价是增加\(g\)-过程参数和识别难度。

### 4. 把多类别题推广为任意依赖题组

链式结构与PCM总分模型形式等价，但任意知识结构可区分同分不同路径。因此直接KST-IRT比把所有testlet压成总分更一般。

## 文章对实务的判断规则

遇到强LD时，不应立刻增加一个随机因子或把斜率推大。先问：

1. 是否有内容理论支持某些潜在模式不可能？
2. 依赖是否有方向或顺序？
3. 题组是否只是一条链，还是存在分支？
4. 稀有模式应被解释为合法但少见，还是结构违反加误差？
5. 需要保留普通单题IRF的参数解释吗？

这些答案决定使用多维SRF、RD、OD/CD、copula、SLD还是KST-IRT。
