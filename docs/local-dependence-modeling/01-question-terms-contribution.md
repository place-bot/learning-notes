# 研究问题、术语与贡献

## 为什么局部依赖是根本问题

局部独立（local independence, LI）要求：一旦控制测验要测的潜在构念，题目反应之间不再有系统关系。
如果这一条件失效，联合似然的乘积形式就不成立，项目难度、区分度和能力估计都可能偏误。

一个典型后果是区分度膨胀。两题若共享材料、解题步骤或表述，模型却把重复证据当成两份独立证据，
会把两题的斜率或因子载荷估得过大。测验信息也可能被高估。

## 文献为什么混乱

过去四十年出现了大量诊断指标和模型，但不同传统使用不同名称：

| 名称 | 典型来源 | 直观含义 |
| --- | --- | --- |
| SLD | surface local dependence | 共享题干、内容相似、位置接近、答案复制等表层依赖 |
| ULD | underlying local dependence | 模型遗漏了共同潜在特质 |
| RD | response dependence | 后一道反应以先前反应为条件 |
| trait dependence | 特质依赖 | 与ULD基本同义 |
| OD | order dependence | 由呈现顺序或学习阶段造成的非对称依赖 |
| CD | combination dependence | 题目组合整体产生对称交互，例如共同刺激或Gestalt效应 |

这些概念的现象描述可能相近，但数学机制不同。例如RD与OD都可以产生非对称列联表：

- RD把联合概率按链式法则分解；
- OD直接重新参数化整个联合分布。

类似地，CD与SLD都能增加一致反应，但CD通过联合log-linear交互实现，SLD则可表示成含结构性分支的混合。

## 单维性不等于局部独立

这篇文章特别纠正一个常见误解：IRT必须单维才能局部独立。

事实上：

- 多维模型中，只要把所有相关维度都条件化，题目仍可局部独立；
- 单维模型中，两道题也可能直接影响彼此，从而局部依赖。

所以维度数和局部独立性是两个问题：

\[
\text{dimensionality}
\neq
\text{local independence}.
\]

遗漏维度可以导致LD，但并不是LD的唯一来源。

## 仅靠拟合指标不能识别机制

一般拟合统计量往往同时对以下问题敏感：

- 局部依赖；
- 维度设定错误；
- 单调性违反；
- 潜在特质分布设定错误。

因此拒绝模型并不能告诉我们LD来自哪里。更棘手的是，多维IRT与“单维但局部依赖”的模型可能经验不可区分；
不同机制还可能产生相同的多分相关。文章的目标不是再给一个检验量，而是区分这些生成机制。

## 统一视角的两个基本对象

作者借用知识空间理论的抽象语言，认为IRT、KST和CDA都在描述：

\[
\text{潜在能力、属性或知识}
\longrightarrow
\text{题目掌握}
\longrightarrow
\text{实际作答}.
\]

只需要两个基本对象：

1. **结构（structure）**：列出一个领域中允许存在的状态；
2. **过程（process）**：给出两个结构之间的条件概率关系。

再加上两种运算：

1. **因子化（factorization）**：把概率写成多个概率的乘积；
2. **重新参数化（reparameterization）**：用logit、probit、log等链接函数赋予概率具体形式。

## 论文的核心贡献

文章提出两个主要LD家族：

### 概率性局部依赖

\[
\mathcal K=2^Q.
\]

所有模式都允许，LD通过SRF的函数形式改变它们的概率。大多数传统IRT-LD方法属于这一类。

### 确定性局部依赖

\[
\mathcal K\subsetneq2^Q.
\]

某些潜在模式由结构排除；若实际数据仍出现这些模式，则用猜测、失误等\(g\)-过程恢复。

“确定性”只表示概率建模之前加入了支持集约束，并不表示最终模型没有随机性。

## 文章声称的四个优势

1. 根据现象是否存在理论结构零，选择更合适的模型家族。
2. 解释为什么中高SLD有时需要极端ULD载荷才能模仿。
3. 用结构零表达极强依赖，避免把IRT斜率或交互参数推到极端。
4. 统一多类别题与依赖二元题，并把testlet从总分链推广到任意结构。

## 研究边界

本文只研究分类反应变量和相应概率模型。连续反应因子分析、残差分析等不在直接范围内；不过二参数IRT与
二分变量因子分析之间的已知对应，使许多结论可迁移到后者。
