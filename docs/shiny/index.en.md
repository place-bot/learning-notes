# R Shiny

This part is an introduction to R Shiny. The goal is not to write a complete enterprise application, but to first master an interactive data application that can be run, displayed, and deployed.

## Learning sequence

1. [Learning path](intro.md): First look at the 7-day learning plan and the packages that need to be installed.
2. [Day 1 Hello World](day1.md): Complete the first Shiny App.
3. [Day 2 Layout and Theme](day2.md): Organize the page structure and theme.
4. [Day 3 Input control](day3.md): Learning user input.
5. [Day 4 Output display](day4.md): Display charts, tables and text.
6. [Day 5 Reactive Programming](day5.md): Understand reactive, observe and observeEvent.
7. [Day 6 Practical item](day6.md): Complete a data exploration tool.
8. [Day 7 Deployment and online](day7.md): Publish the application for others to access.

## What to focus on in this part

|Topic|target|
| --- | --- |
| UI |Build a page that users can understand and operate|
| Server |Connect input, data processing and output|
|reactive programming|Let apps automatically update as users do|
|Data display|Output charts, tables, text and download results|
|deploy|Turn local apps into accessible web apps|
