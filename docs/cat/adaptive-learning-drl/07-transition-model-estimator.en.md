# transition model estimator and virtual students

## 1. Why should we learn transition model?

DQN is called model-free because policy learning does not require explicit knowledge of

\[
\mathcal P(s'\mid s,a).
\]

However, model-free does not mean low data requirements. Complete learning paths for real students take a long time, and exploratory materials can also pose educational risks. Therefore, the paper adds an auxiliary model with the goal of improving real data utilization.

## 2. Input and output of transition model

The model receives the current state and actions:

\[
(s,a),
\]

Output the next state prediction:

\[
\widehat s'=\psi_v(s,a),
\tag{1}
\]

Where \(v\) is the neural network parameter.

If \(s\in\mathbb R^D\), the action number can be one-hot:

\[
\operatorname{onehot}(a)\in\{0,1\}^L.
\]

The input vector is:

\[
\mathbf x_{\text{model}}
=
\begin{bmatrix}
s\\
\operatorname{onehot}(a)
\end{bmatrix}
\in\mathbb R^{D+L}.
\tag{2}
\]

The output layer has \(D\) units.

## 3. supervised learning goals

Transfer collection from history

\[
\mathcal H
=
\{(s_i,a_i,r_i,s_i')\}_{i=1}^H
\]

Fitting:

\[
\min_v
\sum_{i=1}^H
\left\|
\psi_v(s_i,a_i)-s_i'
\right\|_2^2.
\tag{3}
\]

The reward can be recalculated from the predicted next state, so \((s,a,s')\) is mainly used when training \(\psi_v\).

## 4. Transition model structure in the paper

Simulate Study II using:

- a hidden layer;
- 32 hidden units;
- Input is the current status and material;
- The output is a two-dimensional next capability.

The paper does not give a link to the public code repository, nor does it fully report the activation function, training epoch, batch size and regularization in the text. These parameters need to be clearly recorded by yourself when reproducing.

## 5. From real students to virtual students

The training is divided into two phases.

### Phase 1: Fitting environment

\[
\mathcal H_{\text{real}}
\longrightarrow
\psi_v.
\]

### Phase 2: Generate virtual episode

\[
s_{t+1}^{\text{virtual}}
=
\psi_v(s_t^{\text{virtual}},a_t).
\]

DQN can be run in a model environment for many rounds:

```text
limited real students
   ↓
Fit ψ_v
   ↓
Repeatedly reset virtual students
   ↓
DQN Select Material
   ↓
ψ_v generates the next ability
   ↓
Generate a large number of virtual transitions
```

## 6. The exact relationship between model-free and model-based

The basic strategy algorithm of the paper is model-free DQN. After adding \(\psi_v\), the training process utilizes the learned environment model:

- Q updates still use TD form;
- Training transfers can be generated by the model;
- The overall system has elements of model-based data augmentation.

It can be understood as an early Dyna idea: a real experience learning model, and the model is regenerated into experience to help value learning.

## 7. Predictive evaluation indicators for papers

### Coefficient of determination

\[
R^2
=
1-
\frac{
\sum_{i=1}^H
\|s_i'-\widehat s_i'\|_2^2
}{
\sum_{i=1}^H
\|s_i'-\bar s'\|_2^2
}.
\tag{4}
\]

\(\bar s'\) is the mean value of the real next state. \(R^2=1\) means complete prediction.

### RMSE

The paper is written as:

\[
\operatorname{RMSE}
=
\sqrt{
\frac1H
\sum_{i=1}^H
\|s_i'-\widehat s_i'\|_2^2
}.
\tag{5}
\]

It is the square root of the squared average of the vector errors for each transfer.

## 9. Why good one-step prediction may still lead to poor strategy

DQN cares about long trajectories. If there is a small bias in each step:

\[
\widehat s_{t+1}
=
s_{t+1}+\varepsilon_t,
\]

The model then feeds its predictions again as input:

\[
\widehat s_{t+2}
=
\psi_v(\widehat s_{t+1},a_{t+1}).
\]

Errors will accumulate recursively, causing the virtual trajectory to gradually deviate from the real state distribution. This is called compounding error.

The strategy also looks for areas where the model is overly optimistic:

\[
\max_a Q_{\psi_v}(s,a),
\]

thereby exploiting model vulnerabilities. One Step Higher \(R^2\) cannot alone guarantee that strategy values ​​are accurate.

## 10. Stochastic transfer and deterministic mean model

The paper is written as \(\widehat s'=\psi_v(s,a)\), corresponding to point prediction. The transitions in the real environment are randomly distributed:

\[
s'\sim\mathcal P(\cdot\mid s,a).
\]

If \(\psi_v\) only predicts the conditional mean:

\[
\psi_v(s,a)
\approx
\mathbb E[S'\mid s,a],
\]

It loses variance, tail risk, and multimodal results. A more complete model can output:

\[
\widehat{\mathcal P}_v(s'\mid s,a),
\tag{6}
\]

For example:

- Gaussian mean and covariance;
- Beta distribution parameters;
- mixture density network；
- ensemble or Bayesian neural network.

## 11. Monotonicity constraints

The paper assumes no deterioration in ability. Models can be encoded by output deltas:

\[
\widehat{\Delta s}
=
\operatorname{softplus}(f_v(s,a)),
\]

\[
\widehat s'
=
\min\!\left(
\mathbf1_D,
s+\widehat{\Delta s}
\right).
\tag{7}
\]

In this way, each prediction component satisfies:

\[
\widehat s_d'\ge s_d.
\]

If realistic forgetting is studied, this restriction should be removed and time modeled explicitly.

## 12. A more reliable way to use models

Mixed replay can be used:

\[
\mathcal M
=
\mathcal M_{\text{real}}
\cup
\mathcal M_{\text{model}}.
\]

Simultaneously control:

- Virtual sample proportion;
- model rollout length;
- ensemble uncertainty threshold;
- Distance from real data support area.

When the model is uncertain, only perform a short rollout, or directly fall back to conservative actions supported by real data.

## 13. The real problem solved by this part

The transition model estimator solves **data reuse**:

\[
\text{A small amount of real interaction}
\longrightarrow
\text{Approximate environment for repeatable training}.
\]

It doesn't resolve automatically:

- Causal heterogeneity among real students;
- Log strategy selection bias;
- ability estimate error;
- Model extrapolation risk;
- Misalignment of rewards and educational value.
