# MDP, Q function and Bellman equation

This page corresponds to preprint equations (3)–(7), highlighting the meaning of each random variable, conditional probability, and expectation.

## 1. MDP five-tuple

A Markov decision process is written as

\[
\mathcal M
=
\left(
\mathcal S,
\mathcal A,
\mathcal P,
\mathcal R,
\gamma
\right).
\]

|object|meaning|Counterparts in Adaptive Learning|
|---|---|---|
| \(\mathcal S\) |state space|all possible capability vectors|
| \(\mathcal A\) |action space|All recommended materials|
| \(\mathcal P\) |State transition rules|How does your ability change after learning the material?|
| \(\mathcal R\) |reward function|Numerical feedback on the target at the current step|
| \(\gamma\) |discount factor|Relative weight of future rewards|

Policy \(\pi\) is the decision rule to be learned and is usually not placed in the environment quintuple.

## 2. Transfer samples

An interaction results in:

\[
(s,a,r,s').
\tag{8}
\]

The time sequence is:

1. Currently in state \(s\);
2. Strategy selection action \(a\);
3. The environment enters the next state \(s'\);
4. Get reward \(r=\mathcal R(s,a,s')\) based on \(s,a,s'\).

The next state \(s'\) determines the subsequent value, so the experience data must save it.

## 3. Random variables and specific values

Thesis uses:

- \(S^{(t)}\): state random variable at step \(t\);
- \(A^{(t)}\): The action random variable of step \(t\);
- \(R^{(t)}\): Step \(t\) reward random variable;
- \(s,a,r\): The specific values of these random variables.

Case sensitivity avoids confusing "the distribution of the next state" with "the actual observed next state".

## 4. One-step transition probability

The first draft formula (3) is

\[
\mathcal P^{(t)}(s'\mid s,a)
=
\Pr\!\left(
S^{(t+1)}=s'
\mid
S^{(t)}=s,
A^{(t)}=a
\right).
\tag{9}
\]

It answers:

> The current ability is \(s\). If the material \(a\) is selected in this round, what is the probability that the next round’s ability will be \(s'\)?

In the continuous state, \(\mathcal P\) should be understood as the conditional probability density or transfer kernel.

## 5. Markovianity

The first draft formula (4) is

\[
\Pr\!\left(
S^{(t+1)}
\mid
A^{(t)},S^{(t)},\ldots,A^{(0)},S^{(0)}
\right)
=
\Pr\!\left(
S^{(t+1)}
\mid
A^{(t)},S^{(t)}
\right).
\tag{10}
\]

Given the current state and current action, earlier history does not additionally improve the prediction of the next state.

This property requires that the state contain a summary of the history that relates to the future. If fatigue, study duration, number of material repetitions and prior study paths still affect the learning effect, the status can be expanded to

\[
s_t
=
\left(
\boldsymbol\theta_t,
f_t,
\Delta t_t,
\mathbf c_t
\right),
\]

Among them, \(f_t\) represents fatigue, \(\Delta t_t\) represents the time since the last learning, and \(\mathbf c_t\) represents the material usage count.

## 6. Time homogeneity

The first draft formula (5) is

\[
\mathcal P^{(t_1)}(s'\mid s,a)
=
\mathcal P^{(t_2)}(s'\mid s,a).
\tag{11}
\]

It means that the same state and action have the same transition rules at different times. The time superscript can be omitted if satisfied:

\[
\mathcal P(s'\mid s,a).
\]

Markovianity discusses historical conditions, and temporal homogeneity discusses whether laws change over time. The two are different conditions.

## 7. Strategy

The deterministic strategy is

\[
\pi:\mathcal S\rightarrow\mathcal A,
\qquad
a=\pi(s).
\]

The random strategy is

\[
\pi(a\mid s)
=
\Pr(A^{(t)}=a\mid S^{(t)}=s).
\]

DQN deployment often uses the greedy strategy, and \(\varepsilon\)-greedy is used to introduce random exploration during training.

## 8. Discount cumulative return

Starting from time 0:

\[
G^{(0)}
=
\sum_{k=0}^{\infty}
\gamma^k R^{(k)}.
\tag{12}
\]

If the rewards are \(-1,-1,-1,0\) and \(\gamma=0.9\), then

\[
G^{(0)}
=
-1-0.9-0.9^2
=
-2.71.
\]

When reaching a goal faster, there are fewer negative reward terms and the reward is closer to 0.

## 9. Action value under strategy

First draft (6):

\[
Q^\pi(s,a)
=
\mathbb E
\left[
\sum_{t=0}^{\infty}
\gamma^tR^{(t)}
\;\middle|\;
S^{(0)}=s,
A^{(0)}=a;
\pi
\right].
\tag{13}
\]

It means:

> Now at \(s\), the first step is to choose \(a\), and then follow \(\pi\). What is the expectation of the final discount return?

Desired to average simultaneously:

- Randomness of learning transfer;
- Subsequent random strategy actions;
- All trajectories generated by these randomnesses.

## 10. Optimal action value

\[
Q^*(s,a)
=
\max_\pi Q^\pi(s,a).
\tag{14}
\]

After getting \(Q^*\):

\[
\pi^*(s)
\in
\arg\max_{a\in\mathcal A}
Q^*(s,a).
\tag{15}
\]

If all Q values are negative, the one with the largest value is still chosen because it is closest to 0 and corresponds to fewer expected remaining steps.

## 11. Bellman optimal equation

First draft (7):

\[
Q^*(s,a)
=
\mathbb E\!\left[R^{(0)}\mid s,a\right]
+
\gamma
\int_{\mathcal S}
\mathcal P(ds'\mid s,a)
\max_{a'\in\mathcal A}
Q^*(s',a').
\tag{16}
\]

In the discrete state, the integral is written as a sum:

\[
Q^*(s,a)
=
\mathbb E\!\left[R^{(0)}\mid s,a\right]
+
\gamma
\sum_{s'\in\mathcal S}
\mathcal P(s'\mid s,a)
\max_{a'}Q^*(s',a').
\tag{17}
\]

The right side contains:

1. The expected reward for the current step;
2. The optimal subsequent value obtainable in the next state.

## 12. Step-by-step derivation of Bellman’s equation

Starting from the definition of optimal return:

\[
Q^*(s,a)
=
\mathbb E
\left[
R^{(0)}
+\gamma R^{(1)}
+\gamma^2R^{(2)}
+\cdots
\mid s,a
\right].
\]

Propose the first item:

\[
Q^*(s,a)
=
\mathbb E
\left[
R^{(0)}
+\gamma
\left(
R^{(1)}
+\gamma R^{(2)}
+\cdots
\right)
\mid s,a
\right].
\]

In parentheses is the optimal reward starting from the next state:

\[
R^{(1)}
+\gamma R^{(2)}
+\cdots
\longrightarrow
\max_{a'}Q^*(S^{(1)},a').
\]

So we get:

\[
Q^*(s,a)
=
\mathbb E
\left[
R^{(0)}
+\gamma\max_{a'}Q^*(S^{(1)},a')
\mid s,a
\right].
\tag{18}
\]

This is also the theoretical origin of TD target.

## 13. Uniqueness and compression mapping intuition

Define the Bellman optimal operator:

\[
(\mathcal TQ)(s,a)
=
\mathbb E
\left[
R+\gamma\max_{a'}Q(S',a')
\mid s,a
\right].
\]

When \(0\le\gamma<1\):

\[
\|\mathcal TQ_1-\mathcal TQ_2\|_\infty
\le
\gamma
\|Q_1-Q_2\|_\infty.
\tag{19}
\]

\(\mathcal T\) reduces the maximum gap between the two functions to at least \(\gamma\) times of the original, so there is a unique fixed point \(Q^*=\mathcal TQ^*\). DQN approximates this fixed point with a neural network.
