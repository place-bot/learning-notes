## 2. Common shapes

Assume the batch size is \(B\), the longest wrong/correct answer sequence length is \(L_0,L_1\), the embedding dimension is \(d\), and the number of questions is \(J\).

|Tensor| shape |
|---|---:|
|Wrong question ID| \(B\times L_0\) |
|Correct question ID| \(B\times L_1\) |
|Wrong answer embedding| \(B\times L_0\times d\) |
|Correct answer embedding| \(B\times L_1\times d\) |
| cross score | \(B\times L_0\times L_1\) |
|Four-way splicing status| \(B\times4d\) |
|Q value for all questions| \(B\times J\) |
|Action question number| \(B\) |
| reward / done / target | \(B\) |

## 3. Does NCAT generate a complete set of test papers each time?

Only the next question is output for each decision. After getting the student's real-time answer, the status is updated, and then the next question is output. The final sequence is therefore generated by the interaction between the student and the strategy.

## 4. The policy parameters are not updated after training is completed, why are they still adaptive?

Because the input state changes in real time:

\[
Q_\phi(s_t,\cdot)
\longrightarrow
Q_\phi(s_{t+1},\cdot).
\]

The same set of fixed parameters produces different item rankings for different answer histories.

## 5. Is the Q value the probability of correct answer?

The Q value is the discounted cumulative reward estimate after selecting a certain question. The probability of a correct answer is given by the response model \(M(q\mid\theta)\).

## 6. Why do I still need IRT or NCDM?

NCAT is responsible for deciding which question to ask; the response model is responsible for converting observed answers into student parameters and calculating the prediction loss on the query question. The division of labor between the two is different.

## 7. Why can’t query questions be included in student updates?

query is a set of held-out evaluations. If it participates in student parameter fitting at the same time, the outer loss will leak information, making it impossible to evaluate the generalization value of the selected support question.

## 8. If there is no query answer during deployment, how to calculate reward?

Training rewards are not calculated during deployment. The strategy has learned the state-action value in the offline stage, and only needs the current real answers and the trained network to go online.

## 9. Is the first question the same for every student?

The first question is the same when there are no student covariates, the same empty state, the same set of available questions, and using deterministic argmax. Temperature sampling, different available sets, prior information, or demographic/historical covariates may make the first question different.

## 10. Why are there separate channels for correct and incorrect answers?

The two response types differ in frequency and meaning. Different channels can model similar responses separately, and then use cross-attention to compare inconsistencies on related questions.

## 11. Can Contradiction Learning directly identify guesses and mistakes?

It learns response contradiction representations consistent with these phenomena. The attention score itself is not a calibrated guess/slip probability. Simulations with ground truth, external annotations, or specialized latent variable models are required for stronger identification.

## 12. Will average pooling lose the order of answers?

Yes. The paper adopts the assumption that ability is stable during the short test period and order is not important. If learning, fatigue or time effects are present, location, time and feedback information should be included.

## 13. What is the difference between epsilon, gamma and temperature?

- \(\varepsilon\): Random exploration actions during training;
- \(\gamma\): the weight of future reward in TD target;
- \(\nu_t\): The smoothness of the Q value softmax during testing.

## 14. Can temperature sampling ensure safe exposure?

It spreads the path and reduces the average exposure in the paper, but does not guarantee that any question will fall below the specified maximum exposure. Hard quotas or accept/deny controls still need to be implemented separately.

## 15. Does NCAT automatically satisfy content balance?

The paper observes that knowledge point coverage increases rapidly, but there are no blueprint constraints. Content upper and lower bounds should be added explicitly through action mask, constraint reward or shadow test.

## 16. Why is reward often a negative number?

The paper uses the inverse of query BCE:

\[
r_t=-L_t\le0.
\]

The smaller the loss, the closer the reward is to 0, and the larger the Q value is.

## 17. Why is every step counted as query loss?

CAT may stop at different lengths. By incorporating the losses at each step into the goal, you can train topic selection strategies that are also effective at earlier stages.

## 18. Does a discount factor less than 1 change the objectives of the paper?

Yes. The outer formula of the paper gives equal weight to each step; discounted rewards pay more attention to early rewards. When reproducing, the approximation should be clarified and \(\gamma\) sensitivity analysis should be performed.

## 19. Why are offline candidate questions limited to questions that students have answered?

The environment only has the real historical answers to these questions, which can simulate the state transition after selection. The counterfactual result of the unanswered question is unknown.

## 20. How to support new questions?

The embedding and output layer of the original model are bound to fixed question numbers. It can be changed to a matching function between the state encoder and the item content encoder, and new questions can be expressed using item parameters, knowledge points and text semantics.

## 21. What is the core algorithm difference between NCAT and BOBCAT?

BOBCAT learns the strategy through the meta-gradient of double-layer optimization; NCAT learns the Q function through reward, Bellman target and TD update. Both re-determine the next question after each new answer.

## 22. What should you check first when reproducing?

Priority checks:

1. Student-level data leakage;
2. support/query leak;
3. Current and next state action masks;
4. `done` bootstrap;
5. padding mask；
6. Responsive model student parameter reset semantics;
7. Differences between paper configuration and warehouse configuration;
8. Multiple random seeds and results for each fold.
