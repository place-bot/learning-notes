#fine-tuning: ULMFiT (2018)

**Universal Language Model Fine-tuning for Text Classification** turns "how to stabilize fine-tuning language model" itself into a research problem. The concept of fine-tuning is earlier than this article; ULMFiT was chosen because it systematically proposed discriminative fine-tuning, slanted triangular learning rates and gradual unfreezing, and directly affected the subsequent NLP migration paradigm.
