# Language modeling: Bengio et al. (2003)

**A Neural Probabilistic Language Model** is one of the founding papers on neural language model and learning vocabulary. The language model has an earlier history; this document represents a key transition from discrete n-gram smoothing to "joint learning of word vectors and conditional probability neural networks".
