# pretraining: Dai & Le (2015)

The **Semi-supervised Sequence Learning** system demonstrates first training an LSTM with unlabeled sequences and then initializing the supervised task with these parameters. The history of pretraining is earlier; this paper is suitable for connecting "language modeling pretraining" with later ULMFiT, GPT, and BERT.
