## Adjacent Tools

- [vLLM](https://docs.vllm.ai/): Inference engine for high-throughput GPU serving.
- [Text Generation Inference](https://huggingface.co/docs/text-generation-inference/): Model serving tool for Hugging Face.
- [PEFT](https://huggingface.co/docs/peft/): LoRA and other parameters efficient fine-tuning method library.
- [Accelerate](https://huggingface.co/docs/accelerate/): Device placement and distributed training/inference auxiliary library.
