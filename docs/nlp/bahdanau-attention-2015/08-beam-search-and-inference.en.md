# Beam Search and Inference

## 1. Sequence search target

\[
\widehat{\mathbf y}
=
\arg\max_{\mathbf y}
\log p(\mathbf y\mid\mathbf x)
=
\arg\max_{\mathbf y}
\sum_i\log p(y_i\mid y_{<i},\mathbf x).
\]

The candidate space grows exponentially with vocabulary and length, and approximate search is actually used.

## 2. Greedy and beam search

Greedy decoding only retains the word with the highest current probability at each step. Beam search retains \(B\) prefixes, expands candidate words for each prefix, and then leaves the optimal \(B\) according to the cumulative cost:

\[
C(\mathbf y_{1:i})
=
-\sum_{t=1}^{i}
\log p(y_t\mid y_{<t},\mathbf x).
\]

Paths encountering \(\langle EOS\rangle\) enter the completion set.

## 3. Status of each beam

Different prefixes have different

\[
\mathbf s_i,\qquad
\boldsymbol\alpha_i,\qquad
\mathbf c_i.
\]

The search program should also save the token prefix, cumulative cost, decoding status and completion flag. Source annotations are shared by all beams.

## 4. Length preference

Each conditional log probability is no greater than 0, and the original sequence scores tend to be biased towards short translations. Common treatments include length normalization, length penalty, minimum length, and coverage penalty. They alter the decoding criteria and should be reported independently.

## 5. Boundary between paper and code

The paper describes the use of beam search, but does not explicitly report beam width. The author's GroundHog code shows historical implementations of maintenance candidates, masking \([UNK]\), optional length normalization, and length bounds. Configurations not reported in the main result still constitute recurrence uncertainty.

## 6. \([UNK]\) and two sets of BLEU

The vocabulary only retains the 30,000 most frequent words in each language, and other words are mapped to \([UNK]\). Thesis report:

- **All**: complete test set;
- **No UNK**: Neither the source sentence nor the reference translation has a subset of unknown words, and the model is prohibited from generating \([UNK]\).

No-UNK result describes the situation where vocabulary coverage is relatively sufficient and needs to be explained separately from the complete test set.

## 7. Teacher forcing and deployment

\(y_{i-1}^{\text{gold}}\) is used for training, and \(\widehat y_{i-1}\) generated by the model is used for inference. Early errors change subsequent state and attention. Beam search retains multiple prefixes at the same time, which can alleviate search errors caused by a single greedy decision, but it still cannot eliminate the training-inference distribution shift.

## 8. Simplified algorithm

```python
beams = [(0.0, [BOS], initial_state)]
finished = []

for step in range(max_length):
    candidates = []
    for cost, tokens, state in beams:
        alpha, context = attend(state, annotations)
        new_state, log_probs = decoder_step(
            tokens[-1], state, context
        )
        for token in top_tokens(log_probs, beam_size):
            new_cost = cost - log_probs[token]
            if token == EOS:
                finished.append((new_cost, tokens + [token]))
            else:
                candidates.append(
                    (new_cost, tokens + [token], new_state)
                )
    beams = keep_best(candidates, beam_size)
```

Engineering implementations usually vectorize the beam dimensions and rearrange the hidden states according to the parent path index.

## 9. Main calculations

Each target step includes decoder updates for \(B\) paths, attention to \(T_x\) source positions, and 30k vocabulary readouts. Increasing beam width will increase search coverage and increase time, memory and state management costs.

## Summary of this page

Attention determines which source information is read at each step, and beam search determines which target prefixes are retained. Reproduction should also report model parameters, vocabulary strategy, beam width, length rules and \([UNK]\) processing.
